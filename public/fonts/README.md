Verified with the already available FontTools 4.62.1 before inclusion:

- OS/2 weight classes: Regular 400, SemiBold 600, Bold 700.
- Each font maps 451 Unicode code points, including printable ASCII (U+0020–007E)
  and assigned Thai characters U+0E01–0E3A and U+0E3F–0E5B.
- Original TTF files are used without conversion or subsetting. The local WOFF2
  encoder lacks Brotli; no dependency was installed. Total font payload: 349,040 bytes.
- CSS uses `font-display: swap` and same-origin URLs compatible with `font-src 'self'`.
