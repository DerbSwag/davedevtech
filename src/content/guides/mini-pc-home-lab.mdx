Mini PC เป็นจุดเริ่มต้นที่ดีสำหรับ Home Lab เพราะใช้พื้นที่และพลังงานน้อย แต่ยังรันบริการภายในบ้านได้หลายแบบ เช่น file server, Docker, Home Assistant หรือระบบทดสอบงาน

## เลือกสเปกจากงานที่จะทำ

สำหรับงานพื้นฐาน เลือก CPU รุ่นประหยัดพลังงานที่มีหลาย core, RAM เริ่มต้น 16 GB และรองรับการเพิ่มเป็น 32 GB ได้ หากตั้งใจรัน virtual machines หลายตัว RAM 32 GB ขึ้นไปจะคล่องตัวกว่า

ตรวจสอบจำนวนช่อง M.2 และ SATA ก่อนซื้อ รวมถึงการเปลี่ยน SSD ได้สะดวก แนะนำให้แยกข้อมูลสำคัญออกจากเครื่องและมี backup เสมอ

## Network และการระบายความร้อน

พอร์ต 2.5GbE มีประโยชน์กับ NAS หรือการโอนไฟล์ขนาดใหญ่ ส่วนงานทั่วไป Gigabit Ethernet ก็เพียงพอ ควรอ่านรีวิวเรื่องเสียงพัดลม อุณหภูมิ และการใช้พลังงานต่อเนื่องก่อนเลือกซื้อ

## เช็กลิสต์ก่อนตัดสินใจ

- RAM และ SSD เปลี่ยนหรือเพิ่มได้
- มีพอร์ต network ตามรูปแบบการใช้งาน
- รองรับระบบปฏิบัติการและ virtualization ที่ต้องการ
- มีประกันและอะไหล่ในประเทศ
